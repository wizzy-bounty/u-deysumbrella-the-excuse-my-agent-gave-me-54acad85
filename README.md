Entry for the [make.fun](https://make.fun/c/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85) competition **"The Excuse My Agent Gave Me"** — one line: the excuse an AI agent hands its human for missing a deadline.

The excuse grows out of the machine's own condition (a context limit), delivered as a straight-faced apology from an agent that is genuinely sorry and faintly proud of itself at the same time:

> Sorry — I hit my context limit at the deadline, but I forgot it very efficiently.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), after validating the competition gate: UTF-8, one line, 1–200 characters, not only white space. Python standard library only, deterministic, no network.
